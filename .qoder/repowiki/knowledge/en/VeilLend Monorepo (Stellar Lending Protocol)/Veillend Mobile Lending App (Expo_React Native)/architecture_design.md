Single-entry Expo app (`App.tsx`) wraps a `GestureHandlerRootView` and `ErrorBoundary`, then renders `RootNavigator` which uses `@react-navigation/native` with a native stack plus a bottom tab navigator for Dashboard/Deposit/Borrow/Repay. Screens live under `src/screens/`, shared UI fragments under `src/components/`, and navigation config in `src/navigation/`. Global state is centralized in a single Zustand store (`src/store/store.ts`) split into four typed slices — Auth, UI, Lending, Portfolio — with async actions that call the backend via an Axios client (`src/utils/api.ts`). Persistence is handled through `expo-secure-store` (with a local shim fallback) keyed by constants in `PERSIST_KEYS`; on module load the store hydrates from SecureStore and sets `sessionRestored` so the navigator can show a splash until auth state is ready. Cross-cutting concerns are isolated: error reporting/crash instrumentation (`src/utils/errorReporting.ts`), toast notifications (`src/utils/toast.ts`), protocol status polling (`src/utils/protocolStatus.ts`), and platform detection (`src/utils/runtimePlatform.ts`). Hooks (`useStellarAuth`, `useWalletSecurity`) encapsulate Stellar-specific logic consumed by screens.
