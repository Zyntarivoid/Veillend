Two-file `#![no_std]` Rust crate built as a `cdylib`/`rlib` via `soroban-sdk = 23.5.3`. `src/lib.rs` defines the on-chain interface: a single `VeilLendContract` struct with `#[contractimpl]` entrypoints (`initialize`, `configure_asset`, `set_oracle_price`, `update_asset_caps`, `deposit`, `borrow`, `repay`, `withdraw`, `accrue_interest`, plus read-only getters). All persistent state is keyed by a single `DataKey` enum (admin, asset flags, per-user `Position`, per-asset `InterestState`, `AssetReserve`, caps, totals, paused flag) stored under `env.storage().persistent()` and instance storage. A separate `src/interest.rs` module isolates the fixed-point accrual math (`RATE_SCALE = 1e9`, linear APR model with `BASE_RATE_BPS`/`SLOPE_BPS`, piecewise-linear utilization curve) behind pure functions `compute_accrual` and `compute_accrued_position`; the contract calls these from every mutating entrypoint to advance indexes before reading/writing balances. Admin-gated methods validate caller against stored `Admin` via `require_auth()`. Circuit breaker (`Paused`) blocks deposit/borrow but leaves repay/withdraw open. Versioning is explicit via `CONTRACT_VERSION`, `STORAGE_SCHEMA_VERSION`, and `STORAGE_SCHEMA_ID` (`VLENDV2`) exposed through `contract_metadata`. Tests live in `tests/integration.rs` using `soroban_sdk::testutils::{Address, Ledger}` with `Env::default()` and `mock_all_auths()`, and snapshot tests in `test_snapshots/` capture event payloads for regression.
