The repository is a flat monorepo where each product lives in its own top-level directory (`veilend-soroban`, `veilend-backend`, `veilend-web`, `veilend-mobile`) and communicates only through well-defined boundaries: the Soroban contract on Stellar serves as the single source of truth for lending state, the NestJS backend indexes Soroban events into PostgreSQL and exposes REST APIs consumed by both the web and mobile apps, while the Next.js web app and Expo mobile app are independent frontends that connect to the backend and interact with the contract via Freighter. Cross-cutting orchestration happens at the repo root: `Cargo.toml` declares a Rust workspace for the Soroban contracts with hardened release profiles (`opt-level=z`, LTO, panic=abort), `.github/workflows/` provides one CI file per child (soroban-ci.yml, veilend-backend.yml, web-ci.yml, mobile-ci.yml) scoped to each directory's paths, and `vercel.json` configures SPA rewrites for the web frontend on Vercel.
