Built on Next.js 16 with the App Router under `src/app/`. The root `layout.tsx` sets global fonts, metadata, and wraps all routes in a `WalletProvider` from `@/context/WalletContext`, which composes the `useStellarWallet` hook (`src/hooks/useStellarWallet.ts`) into a React Context that exposes `isConnected`, `isAuthenticated`, `address`, and connect/disconnect actions — the single source of wallet state consumed by every page and component. Pages are split into a route-group `(dashboard)` landing page and a nested `dashboard` route with dedicated `error.tsx`/`loading.tsx` skeletons. A Next.js Route Handler at `src/app/api/campaign-events/route.ts` posts campaign events to the backend. UI is built from shadcn/ui primitives under `src/components/ui/` (Button, Card, Dialog, Badge, Progress, Skeleton, etc.) composed into domain components like `WalletConnect`, `WalletStatus`, `CampaignTracker`, `TrackedLink`, and `AmountInput`. Cross-cutting concerns live in `src/lib/`: `stellar/` for Freighter SDK calls, `api/` and `hooks/` for data fetching abstractions, `types/` for shared TS types, `validation/` for runtime checks, plus `campaignAnalytics.ts`, `config-validation.ts`, and `utils.ts`. Environment configuration is validated eagerly at module load time via `next.config.ts` calling `validateConfig()`, so missing `.env` variables surface during `next dev`/`next build`.
